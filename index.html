PhantomAOS

PhantomAOS is a from-scratch terminal and Linux environment for Android, written in Rust. It is built for security researchers, ethical hackers and developers, and needs no root.

What makes PhantomAOS different

  • Rust core engine. A real forkpty() terminal with full job control (Ctrl+C, Ctrl+Z, background processes), not a fake shell wrapper.
  • No root required. Linux environments run isolated through PRoot.
  • Memory-safe by design. A security tool should not be an attack surface itself.
  • Built for the job. Split-screen multi-terminal, macro keyboard, SSH/VNC client and a curated package manager (paos).

Project status

PhantomAOS is in early development. The JNI bridge and the real PTY engine are working. It is not yet ready for general use.

Build from source

The Rust core (core/phantom-core) is cross-compiled for Android with GitHub Actions and linked into the Android app through JNI. Source and build instructions are in the PhantomAOS repository. PhantomAOS is released under the GPL-3.0 license.

Authorized use only

Use PhantomAOS only on systems and networks you own or have written permission to test. Unauthorized access or scanning is illegal, and the maintainers are not responsible for misuse.
